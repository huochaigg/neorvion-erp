# V6 — 采购管理

本版完成供应商档案、采购单、采购明细、审核状态机、RBAC、React 页面与联调。

审核通过进入待收货，**不**增加库存。收货 / 入库 / 部分收货 / 退货 / 付款不在本版。

下一完整版本建议 V7 采购收货与入库，或销售订单管理。不要在本版继续往下做。

详见 `docs/purchases.md`。

## 数据表

迁移 `20261005_0011`：

- `suppliers`：`UNIQUE(tenant_id, code)`。未填 code 时 flush 后写 `SUP` + 10 位 id。
- `purchase_orders`：`UNIQUE(tenant_id, order_no)`。单号 `PO` + 年 + 6 位 id。供应商 / 仓库复合外键保证同租户。
- `purchase_order_items`：`UNIQUE(tenant_id, purchase_order_id, sku_id)`。`quantity > 0`，`received_quantity` 默认 0 且不超过采购数量。金额不落库。

## 状态机

`DRAFT` → `PENDING_APPROVAL` → `WAITING_RECEIPT`。另有 `REJECTED`、`CANCELLED`。不保留 `APPROVED`：通过后同事务直接待收货。

规则集中在 `purchase_state.py`。状态流转用条件 UPDATE + `rowcount`，冲突返回 `PURCHASE_ORDER_STATE_CONFLICT`。草稿编辑用 `SELECT FOR UPDATE` 后整体替换明细。

## API

- 供应商：`/api/v1/suppliers` CRUD + `/status`
- 采购单：`/api/v1/purchase-orders` 列表/创建/详情/编辑
- 动作：`/submit` `/approve` `/reject` `/cancel`

## 前端

菜单「采购管理」：采购单、供应商管理。创建 / 详情 / 编辑不进菜单。详情用 Steps 展示创建 → 提交 → 审核 / 驳回 → 待收货。

## 权限

新增 `purchase:update` / `submit` / `cancel` 以及完整 `supplier:*`。OPERATOR 不能审核。已被采购单引用的供应商、仓库、SKU 不能删除。
