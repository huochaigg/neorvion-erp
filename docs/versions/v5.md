# V5 — 库存管理

本版建立 `Tenant + Warehouse + SKU → Inventory`：实际库存、预占、可用库存（计算字段）、初始化、调整、流水、并发锁、RBAC、React 页面与联调。

不开发采购单、销售订单、正式收货入库/销售出库页面、物流、发货。下一完整版本建议 V6 采购管理。

详见 `docs/inventory.md`。

## 数据表

迁移 `20261004_0010`：

- `inventories`：当前账面。`UNIQUE(tenant_id, warehouse_id, sku_id)`。CHECK：数量非负且预占不超过实际。
- `inventory_transactions`：不可变流水。纠错靠新的调整记录，不改历史。
- 可用库存不落库，等于 `quantity - reserved_quantity`。
- `version` 默认 0，关键修改 +1。正式调整用悲观锁；预占用条件 UPDATE；乐观锁仅演示接口。

## 事务与锁

库存变更和流水必须同一事务提交，失败则一起回滚。

- 手工调整：`SELECT ... FOR UPDATE` 锁当前行
- 预占 / 释放 / 出库扣减：`UPDATE ... WHERE 可用量够` + `rowcount`
- 乐观锁演示：`UPDATE ... WHERE version = 旧值`，冲突返回 `INVENTORY_CONFLICT`

## API

- `GET/POST /api/v1/inventory`（列表 / 初始化走 `/initialize`）
- `GET /api/v1/inventory/{id}`
- `POST /api/v1/inventory/{id}/adjust`
- `GET /api/v1/inventory/transactions`
- 内部：`reserve` / `release` / `deduct-reserved` / `optimistic-adjust`
- `GET /api/v1/product-skus` SKU 远程搜索

## 前端

菜单「库存管理」：库存列表 `/inventory/list`、库存流水 `/inventory/transactions`。详情 `/inventory/:id` 不进菜单。无「手动预占」按钮。

## 权限

新增 `inventory:initialize`、`inventory:adjust`、`inventory:transaction:read`。保留 `inventory:inbound` / `inventory:outbound`。权限树增加初始化、调整、查看流水。已被库存引用的仓库和 SKU 不能删除。
