# V11 — 销售退货与售后

销售售后申请、审核、退货收货入库、退款状态。不接真实支付退款 API。

## 范围

- 三种售后：`REFUND_ONLY` / `RETURN_AND_REFUND` / `RETURN_ONLY`
- 可退数量 = 已出库 − 有效售后占用；待审核即占用
- 审核可下调数量和金额；拒绝释放占用
- 退货单、部分收货、GOOD 入普通库存、残次品只记已收
- `RETURN_INBOUND` 流水；不恢复 reserved
- `RefundRecord` 历史；失败后可再试；人工确认外部退款
- ERP：售后单、退货单、退款记录；销售订单详情可申请售后
- 权限：`after_sale:*`、`return_order:*`、`refund:*`

## 不在本版

真实支付宝 / 微信 / Stripe 退款、平台售后回传、换货重新发货、采购退货、财务凭证、次品库存台账、客服工单、AI Agent。

完成 V11 后停止，不要自动开始 V12。
