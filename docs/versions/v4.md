# V4 — 仓库管理

本版把 Warehouse 做成独立主数据闭环：建仓、编码、默认仓、启停、删除规则、多租户隔离、RBAC、React 页面与联调。

不开发库存数量、可用库存、预占、库存流水、采购入库、销售出库、收货、发货、订单、物流。下一完整版本是 V5 库存管理。

详见 `docs/warehouses.md`。

## 数据表

迁移 `20261003_0009`：

- `warehouses`：租户仓库档案
- `UNIQUE(tenant_id, code)`；`code` 创建时可空，flush 后按自增 id 生成 `WH` + 10 位数字
- 联合索引 `(tenant_id, status)`、`(tenant_id, type)`
- `is_default` 不靠数据库部分唯一约束，由 Service 事务 + `SELECT ... FOR UPDATE` 保证每租户最多一个默认仓

## API

均需登录和 `X-Tenant-ID`。

- `GET/POST /api/v1/warehouses`
- `GET/PATCH/DELETE /api/v1/warehouses/{id}`
- `PATCH /api/v1/warehouses/{id}/status`
- `POST /api/v1/warehouses/{id}/set-default`

第一个仓库自动默认。切换默认仓必须同一事务提交新旧两行。停用仓不能设为默认。默认仓不能停用，也不能在还有其他仓库时删除。

## 前端

菜单「仓库管理」：`/warehouses`。列表 + Drawer 新增/编辑/查看。Query Key 带 `tenantId`。

## 权限

新增 `warehouse:read/create/update/disable/delete`。设默认归 `warehouse:update`。权限树增加「仓库管理」目录。WAREHOUSE 角色默认可维护档案，不能停用或删除。
