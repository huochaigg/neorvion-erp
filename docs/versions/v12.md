# V12 — 采购退货

把已收货商品退给供应商：独立采购退货单、审核、退货出库扣减 available、供应商退款记录。不修改原采购计划数量和已收数量。

## 本版做了

- `PurchaseReturn` / `PurchaseReturnItem`：草稿不占用可退；提交后占用
- 可退 = `received_quantity` − 有效退货占用，不是采购计划数量
- `PurchaseReturnOutbound` / Item：每次实际出库独立记录；确认后扣 `quantity`，`reserved` 不变
- 流水 `PURCHASE_RETURN_OUTBOUND`，引用采购退货单
- `SupplierRefundRecord`：失败/成功历史；确认退款不再动库存
- `NO_REFUND` 全部出库即完成；`REFUND` 还要退款到账
- 并发提交、并发确认出库、多 SKU 一项失败整单回滚
- ERP：采购退货、退货出库、供应商退款页面；采购单详情可创建退货并展示可退数量
- 权限 `purchase_return:*`、`supplier_refund:*`

## 本版不做

采购换货、补货单、真实银行退款、应付账款、采购发票、财务凭证、税务、次品库存、复杂质检、AI Agent。

完成 V12 后停止，不要自动开始 V13。
