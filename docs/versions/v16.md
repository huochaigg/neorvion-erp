# V16 腾讯云 OpenCloudOS 生产部署与 GitHub CI/CD

不新增大业务域。不自动登录服务器。不自动 git commit / push / 创建 production 分支。

## 本版做了什么

- 生产 Docker Compose：MySQL 8.4、Redis 7、PostgreSQL+pgvector、erp-api、worker
- 宝塔 Nginx 模板（同域 `/` `/erp/` `/api/`，API 端口 **8011**）
- 第一次手工部署文档 + 日常运维 + GitHub Actions / GHCR
- 备份 / 回滚 / smoke / 机器检查脚本
- Health 增加 `version` / `git_sha`；`ENABLE_API_DOCS`；ERP 生产 `base=/erp/`
- ERP 子应用 TabBar：`@sinm/react-chrome-tabs` Chrome 风格多页签（拖拽排序、关闭、Zustand + localStorage）

## ERP TabBar

只存在于 ERP 子应用，放在 `ErpLayout` 面包屑上方、主内容上方。Shell 不实现全局 Tabs。Tab UI 为 `@sinm/react-chrome-tabs`（官方 Chrome 耳朵造型 + 拖拽排序）。业务状态仍在 Zustand。

- 标题来自 `routes.ts` 的 `title`；`key` 为规范化 pathname（含详情 ID，不含列表 query）
- 监听 `location.pathname`：菜单、浏览器前进后退、地址栏直达都会入 Tab；重定向只保留最终路由
- 工作台 `/dashboard` 固定不可关闭；关闭全部后仍保留并跳回工作台
- 租户切换：Tabs 重置为工作台；带资源 ID 的详情页不在切换瞬间入 Tab（仍由 `TenantChangeBridge` 退回列表）
- 权限刷新后主动丢掉当前用户不可访问的 Tab
- 持久化：`localStorage` 键 `neorvion.erp.tabs.v1`，恢复时过滤已删除路由；权限过滤在权限加载完成后
- **不是**页面 Keep Alive：切 Tab 会卸载 React 页面，未保存表单会丢失；服务端缓存仍走 React Query。未做「刷新当前」（避免 `window.location.reload` 打到 Shell / Wujie）
