# V14 事件中心、操作日志与异步任务

在 V13 报表之上补齐系统可观测与长任务基础设施。不重做 V3–V13 业务流程。

## 交付

- `system_events` Outbox：关键业务动作与主事务同写
- `operation_logs` 只读审计 + `X-Request-ID`
- `async_tasks` / `async_task_logs` + Redis List Worker
- 报表异步导出、任务中心、事件中心、操作日志页面
- RBAC：`event:read`、`operation_log:read`、`task:read/retry/cancel/download`
