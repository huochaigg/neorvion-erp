# V8 — 收货入库与销售出库

本版把采购和销售接到库存上，形成第一条供应链闭环。

采购：待收货 → 收货草稿 → 确认入库 → 实际库存增加 → 部分收货或已收货。

销售：确认预占后自动生成出库单 → 拣货不扣库存 → 确认出库同时减少实际库存和预占 → 部分出库或已出库。

物流、运单、退货退款、财务、平台同步不在本版。不要从本版继续做 V9。

业务说明见 `docs/fulfillment.md`。当前有效范围见 `docs/current-state.md`。

## 采购状态

在 V6 上增加 `PARTIALLY_RECEIVED`、`RECEIVED`。

`WAITING_RECEIPT` 可到部分收货或已收货。部分收货只能再到已收货。已收货不能再创建收货单。

## 销售状态

在 V7 上增加 `PARTIALLY_SHIPPED`、`SHIPPED`。

待出库可到部分出库、已出库，或在尚未出库时取消。一旦有已出库数量，整单不能取消。

## 库存

确认收货调用 `inbound_within_transaction`：`quantity` 增加，预占不变。没有库存行时用保存点创建，撞上唯一约束则改为增加已有行。

确认出库调用 `deduct_within_transaction`：`quantity` 和 `reserved_quantity` 一起减少。可用量通常不变，因为这批货确认订单时已经从可用量划走。

多 SKU 按 `sku_id` 升序。单据、来源单、库存在同一个事务。重复确认拒绝，不重复改库存。

## API 与页面

收货：列表、从采购详情创建草稿、详情确认 / 作废。

出库：列表、详情拣货、确认出库。销售详情可打开已有出库单，或在部分出库后继续生成。

菜单：采购管理增加「采购收货」；库存管理增加「销售出库」。

## 权限

`purchase:receipt:read|create|update|confirm|cancel`

`outbound:read|create|pick|confirm|cancel`

OWNER / ADMIN 全部。OPERATOR 可查看和创建收货草稿、查看出库，不能确认。WAREHOUSE 可收货确认和出库拣货、确认。VIEWER 只读。是否允许仍由 `role_permissions` 决定。
