# V10 — 库存盘点与库存调拨

在 V5 库存台账、V8 入库出库之上增加盘点和跨仓调拨。库存加减继续走 `InventoryService` 的 `*_within_transaction`，不另写一套。

## 范围

- 盘点任务、实盘录入、提交、按差异确认、`STOCKTAKE_ADJUSTMENT` 流水
- 调拨草稿、提交、确认调出、在途、确认调入、`TRANSFER_OUT` / `TRANSFER_IN`
- 状态机、短事务锁、幂等、RBAC、多租户、ERP 页面与测试

## 不在本版

库位、批次、序列号、保质期、波次、独立在途库存表、采购退货、销售退货、财务、真实平台同步、AI Agent。

## 盘点要点

创建时保存 `system_quantity` 快照。确认时 `当前 quantity + difference`，不是覆盖成实盘数。盘点期间不长时间锁库存。盘亏不能使 `quantity < reserved`。

## 调拨要点

调出和调入拆成两个事务。调出只扣 available。在途不属于任一仓库存。目标仓没有 SKU 时复用入库的安全创建。

完成后不要自动进入 V11。
