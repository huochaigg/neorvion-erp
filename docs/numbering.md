# 业务编号

未填编码时：先 `flush` 拿到自增 id，再写成前缀 + 固定宽度 id。**不用 `MAX(code)+1`**，避免并发重复。

| 对象 | 格式 |
| --- | --- |
| 商品 SPU | `PD` + 10 位 id |
| SKU | `SKU` + 10 位 id（也可手填，租户内唯一） |
| 仓库 | `WH` + 10 位 id |
| 供应商 | `SUP` + 10 位 id |
| 客户 | `CUS` + 10 位 id |
| 物流商 | `CAR` + 10 位 id |
| 采购单 | `PO` + 年 + 6 位 id |
| 销售订单 | `SO` + 年 + 6 位 id |
| 采购收货 | `PR` + 年 + 6 位 id |
| 销售出库 | `OUT` + 年 + 6 位 id |
| 物流单 | `SHP` + 年 + 6 位 id |
| 盘点 | `ST` + 年 + 6 位 id |
| 调拨 | `TR` + 年 + 6 位 id |
| 售后 | `AS` + 年 + 6 位 id |
| 退货单 | 领域内独立单号（见售后文档） |
| 退款记录 | `RF` + 年 + 6 位 id |
| 采购退货 | `PRT` + 年 + 6 位 id |
| 采购退货出库 | `PRO` + 年 + 6 位 id |
| 供应商退款 | `SRF` + 年 + 6 位 id |

租户内单号有唯一约束。跨租户允许相同展示号，因为带 `tenant_id`。
