# 企业内部操作规范、产品说明与 FAQ

## 知识库操作规范

1. 上传前确认文件属于当前企业，不要把其他租户资料拷进来。
2. 解析失败先看任务错误，扫描版 PDF 可能无文本，需要 OCR（**当前未实现 OCR**）。
3. 改切片内容会使向量标记 **STALE** 并重建。改 Chunk Size / Overlap 必须**重新切片再 Embedding**，只重建向量不够。
4. 删除文档默认进回收站，检索立即不可见，文件与向量仍保留直到彻底删除。
5. 更新文档会先快照原文件。新版本发布前，旧 ACTIVE 切片仍可检索。

## 产品使用说明

- 智能搜索支持三种策略：VECTOR / KEYWORD / HYBRID。HYBRID 用 **RRF** 融合两路结果。
- 召回调优页可看两路排名和 Rerank 前后。
- 评测数据集：导入问题、标注相关 Chunk、冻结版本、创建实验。
- 单题评测：在数据集详情点“单题评测”，不创建完整实验。不想跑整页实验时用这一入口。

## FAQ

Q: 为什么 KEYWORD 搜中文有时不准？  
A: 使用 simple FTS + trigram + 中文片段 ILIKE，不是 BM25，也没有中文专业分词器。整句 ILIKE 往往匹配不到，需要靠词片段。

Q: 无答案题为什么算成功？  
A: 显式 `is_unanswerable` 的题目，相关集合为空时不计算 Recall，考察的是拒绝编造。

Q: API Key 能改 X-Tenant-Id 吗？  
A: 不能。Key 绑定创建时的租户，不匹配则 403，不能改绑其他租户。
