# 跨境异常与客服话术（模拟）

本文是模拟客服手册，便于 RAG 评测检索，不是真实平台政策。

## 常见异常

1. 地址无法投递：先联系买家更新地址，超时未回复则按海外仓退件流程。
2. 海关查验：向买家说明需要补充资料，不承诺具体放行天数。
3. 少件：核对出库扫描记录。扫描完整则引导签收异常；扫描缺失则补发或退款。
4. 质量争议：要求照片和订单号。未过模拟质保窗口可走退件；超出窗口仅记录。
5. 预占与海外仓不一致：以海外仓 WMS 为准，ERP 需对账，不得直接改其他租户库存。

## 模拟话术

- “我们已为该订单预留下一程运力，但清关进度以当地海关为准，我无法承诺具体日期。”
- “退款成功不代表海外仓已上架，库存恢复以质检结果为准。”

## 与 ERP 知识库的区分

Neorvion ERP 当前实现的是国内仓预占/出库状态机。海外仓库龄、HS 编码、清关资料不属于 ERP 已实现模块。回答时不要把模拟跨境规则说成 ERP 功能。
